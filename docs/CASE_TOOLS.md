# Case tools

## Search case

Choose **Search case** in a case header. Search saved findings, graph objects and connections, dossier fields, case notes, analyst timeline notes, confidence reasoning, and tasks. Search is case insensitive; separate words must all match a record. Phone-number searches also match punctuation differences. Filter by content type and page through 25 results at a time. Search covers original case content, including findings excluded from reports, and never searches another case.

## Entity profiles

Choose **Case tools → Entity profiles**, a graph object's **Open entity profile** link, or an entity result in case search. Profiles show recorded fields, incoming/outgoing connections, explicitly linked evidence, relevant confidence assessments, and tasks linked to those findings or connections. Nearby entities have their own profile links. No name-based association or automatic merging occurs. Separate graph objects remain separate profiles until deliberately merged in the graph.

## Review before sharing

Choose **Case tools → Review before sharing** or the review link in the report builder/preview. The review follows current report selection and saved graph views. It flags unverified and included false-positive findings, hypotheses or supported connections lacking linked findings, missing source attribution, unavailable evidence, missing summary sections or screenshots, empty selected graph views, and unfinished case tasks. Supporting sources cited in relevant confidence assessments are included in the source review.

These prompts do not block exports or certify the report. The review page is an internal workspace and may contain original identifiers even while report redaction is enabled. Share the reviewed report, not the internal review page.

## Case templates

On **Cases**, choose Blank case, Digital footprint review, Organization research, or Incident research before creating a case. Each nonblank starter adds an empty graph with relevant field definitions, three open tasks, and a report outline with blank executive-summary fields. It does not invent evidence or conclusions. Templates apply only at creation and never overwrite an existing case. Each created case receives its own graph/task IDs and can be edited independently.
