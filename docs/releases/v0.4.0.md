# OSINT Menace v0.4.0 — More Sources. Fewer Alibis.

![OSINT Menace v0.4.0 Investigation War Room](https://raw.githubusercontent.com/awesom3alex/osint-menace/v0.4.0/docs/images/osint-menace-v0.4.0-release.png)

OSINT Menace v0.4.0 expands the investigation workspace with new research sources, original email analysis, retained document inspection, and more ways to review and organize findings before sharing them.

## Start here: a new quickstart guide

The **[Quickstart and tool/API guide](https://github.com/awesom3alex/osint-menace/blob/v0.4.0/docs/QUICKSTART.md)** walks through installation and a first investigation, explains all 19 integrated tools and the built-in research features, and identifies which modes run locally, contact public services without a key, accept optional credentials, or require a session/token. It also covers credential setup, backups, and common problems.

Most integrations work without an operator API key. Toutatis needs an Instagram session; optional PhoneInfoga providers and the CourtListener connector have their own credential requirements. Public services can still impose limits or block requests.

## Seven new tool integrations

- **Unfurl / URL Inspector:** decode URL components and supported embedded values locally without visiting the URL.
- **waymore / Historical URL Discovery:** find historical domain URLs through Wayback Machine and Common Crawl in URL-only mode.
- **Subfinder / Passive Subdomains:** gather subdomain leads from the selected public sources, without active resolution.
- **dnstwist / Brand Impersonation:** review a bounded set of look-alike domains through DNS checks.
- **theHarvester / Organization Footprint:** collect infrastructure leads through the selected crt.sh and AlienVault OTX sources.
- **ExifTool / Evidence Metadata:** inspect metadata in a retained original PDF/image without modifying the original.
- **Mail-Parser / Email Evidence:** retain and hash original `.eml` messages, inspect claimed headers and delivery hops, read inert body text, inspect URLs locally, and review attachment metadata and hashes.

These integrations complement the original twelve addons. Findings remain leads for analyst review; account matches, metadata, and email header claims do not independently establish identity or authenticity. Email parsing does not load remote images or execute attachments.

## Expanded research and evidence

- Global web/news search with query previews, filters, selected-result exports, and retained provenance.
- Expanded domain and URL modes in Unified Search.
- A combined telephone panel, U.S. and international address parsing, location candidates, nearby mapped places, and public profile-page extraction.
- Exact-URL archived page history and broader historical URL discovery.
- Retained PDF/image evidence reading with text search, supported OCR, original-file hashes, and portable case backups.

## Investigation and review workflows

- Cross-case identifier comparison with retained analyst decisions.
- Investigation questions with supporting and conflicting evidence and saved revisions.
- Opt-in scheduled source monitoring with changed-text review.
- Reusable research workflows with saved step progress.
- Source expansion, review inboxes, side-by-side entity comparison, and retained identity assessments.
- Case dashboards and health checks for tasks, evidence gaps, unsupported connections, changed sources, and recent activity.
- Selected chronology/report exports, source references, and redaction controls.
- A backup and recovery center with verified case ZIPs and non-overwriting restore previews.

## Cleaner source layout and simpler installation

The repository now has one main installer at its root:

```sh
python3 install.py
```

Application modules, templates, static assets, workers, and pinned addon metadata live in **`osint/`**. Docker/setup/update helpers live in **`deployment/`**, dependency lists in **`requirements/`**, development settings in **`config/`**, and guides and release artwork in **`docs/`**. Tests remain in **`tests/`**. Runtime investigation data stays in the root **`data/`** directory.

The old root application files and setup scripts have been relocated; use the new paths when updating custom launch commands or automation. Docker commands now use:

```sh
docker compose -f deployment/docker-compose.yml up -d
```

The installer builds first, backs up existing data before replacement, checks preservation, and attempts to restart the previous image if replacement checks fail. SQLite preservation checks validate writable snapshots including committed WAL data while leaving the source data untouched. Stable-release notifications and the `python3 install.py --update` workflow are also included.

## Validation

The Python 3.12 suite ran 238 tests successfully, with 15 skips for deferred features or unavailable optional runtimes. All three browser behavior tests and lint checks passed. All seven new integrations passed their local startup checks; these checks do not establish live external-provider coverage.

## Install or upgrade

Start Docker Desktop or Docker Engine with Compose v2. Use Python 3 and Bash on macOS, Linux, or WSL2, then run from the v0.4.0 source folder:

```sh
python3 install.py
```

Open **http://localhost:8088**. The application version and local image tag are **`0.4.0`** and **`osint-menace:0.4.0`**. The first build downloads tool dependencies and international address models. This release provides source; the installer builds the Docker image locally.

For an existing installation, preserve the root `data/` folder and private configuration and update the same source checkout. Resolve local changes before updating. Existing installations with the release updater can check with `python3 install.py --check` and update with `python3 install.py --update`.

See the **[Installation guide](https://github.com/awesom3alex/osint-menace/blob/v0.4.0/docs/INSTALL.md)** for backup locations, migration details, and recovery. Menace has no built-in login; use its web interface on a trusted network with appropriate access controls.

Browser capture extensions, an embedded research browser, and Office document inspection remain future work. General image analysis/reverse-image search remains disabled and deferred; retained-file reading, OCR, and ExifTool metadata inspection are available.
