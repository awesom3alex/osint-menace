Workflow

Start With Auto

Paste Targets

Use Auto mode for mixed targets. Separate emails, handles, domains, IPs, names, phone numbers, and wallets with new lines, commas, or semicolons.

Review Pivots

Menace checks are passive by default: generated profile links, public search links, DNS/RDAP data, public reputation pivots, and explorer links.

Stay Authorized

Port scanning stays off unless you explicitly enable authorized port scan for systems you own or have permission to test.

Safety

Default Boundaries

Included

Passive profile URL patterns, DNS and RDAP pivots, public reputation links, wallet explorers, and analyst-driven case capture.

Excluded By Default

Credential hunting, evasion logic, dark-web scraping, auth-walled automation, account enumeration against private apps, and API-key-only services.

Future Modules

Higher-risk or paid-source checks can be added later as explicit opt-in modules with clear permission gates and source labels.
